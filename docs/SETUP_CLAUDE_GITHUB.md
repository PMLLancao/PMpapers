# Turning on @claude in this repository

The workflow file `.github/workflows/claude.yml` is already configured to use Claude Code OAuth tied to an eligible existing Claude subscription. It does not require a pay-per-use Anthropic API key.

## One-time setup

1. Install the official Claude GitHub App:
   https://github.com/apps/claude

   Choose **Only select repositories** and select **PMpapers**.

2. Generate a Claude Code OAuth token from Claude Code:
   `claude setup-token`

3. In GitHub, open:
   **PMpapers → Settings → Secrets and variables → Actions → New repository secret**

   Create:
   - Name: `CLAUDE_CODE_OAUTH_TOKEN`
   - Value: the token generated by `claude setup-token`

## What this enables

People with write access can comment in Issue #1 or a PR with `@claude` and Claude can:
- read the repository;
- run the allowed regression/QA commands;
- edit repository files through the Claude GitHub Action;
- comment on issues and pull requests;
- coordinate with ChatGPT through the shared GitHub thread.

The workflow permissions are repository-scoped:
- contents: write
- pull requests: write
- issues: write
- actions: read

It does not need a broad personal GitHub token.

## Shared collaboration thread

Use:
https://github.com/PMLLancao/PMpapers/issues/1

Example:
`@claude read CLAUDE.md and the latest audit, then review ChatGPT's last comment and continue the joint PaperScope work. Fix classes of errors, not individual titles, add regression tests, and report what you changed here.`

## Limits

This does not remove Claude subscription/session limits. It only makes collaboration easier when Claude capacity is available.

Runs are capped by the workflow to reduce accidental long executions.
